# Bootstrap pela web

Este repositório substitui anexos de processo. Um Hermes que recebe seu URL deve buscar `PROCESS_MANIFEST.json`, `START_HERE.md` e a skill antes de pedir instruções adicionais.

Arquivos de processo devem vir deste repositório. Dados pessoais, chaves, documentos privados e decisões de negócio pertencem ao usuário e nunca devem ser adicionados ao repositório.

Se uma leitura web falhar, use a URL raw do GitHub. Peça ao usuário o conteúdo de um único arquivo somente se os dois caminhos falharem.
